# Cybersecurity Log Analyzer

A beginner-friendly Python project for analyzing sample authentication logs and identifying potentially suspicious login activity.

## About the Project

The **Cybersecurity Log Analyzer** is a Python-based project created to practice fundamental cybersecurity concepts, log analysis, and automated testing.

It processes sample login log data, helps identify potentially suspicious activity, and generates a report of the analysis.

## Features

- Analyze sample authentication logs.
- Identify suspicious login activity based on the implemented detection rules.
- Generate a text report of the analysis.
- Run automated unit tests to check the analyzer's behavior.
- Use sample data for safe, educational experimentation.

## Technologies Used

- **Python 3**
- **File handling**
- **Unit testing** with Python's `unittest` framework
- **Git and GitHub** for version control and project sharing

## Project Structure

```text
cybersecurity-log-analyzer/
├── analyzer.py
├── sample_logs.txt
├── test_analyzer.py
├── report.txt
└── README.md
```

`report.txt` is generated by the analyzer when the program runs, if configured to do so. It does not need to be uploaded to GitHub.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sihemakammouni-bot/ybersecurity-log-analyzer.git
```

### 2. Open the project folder

```bash
cd ybersecurity-log-analyzer
```

### 3. Run the analyzer

```bash
python analyzer.py
```

If your system uses the `python3` command, run:

```bash
python3 analyzer.py
```

### 4. Run the tests

```bash
python -m unittest test_analyzer.py -v
```

The tests help verify that the analyzer behaves as expected.
